SJF (Preemptive) Analysis

Always picks shortest remaining burst. Minimizes wait time but has many context switches.

SJF (Non-Preemptive) Analysis

Once started a job runs to completion. Fewer context switches but short jobs arriving later wait for a running long job.

Priority Analysis

Favors lower priority numbers. Can cause starvation for low-priority tasks.

8

Final Conclusion

Conclusion & Recommendation

Based on the simulation: SJF(Pre) & SJF(NP) achieved best average waiting time, SJF(Pre) & SJF(NP) achieved best average turnaround time, and SJF(Pre) & SJF(NP) had best average response time.

Main Trade-off: SJF(Preemptive) minimizes wait time but causes many context switches. SJF(Non-Preemptive) reduces context switches but a long job already running blocks newly arrived short jobs. Priority ensures urgent tasks run first but risks starvation for low-priority processes.
